# Curve25519 types

`Curve25519Base`, `Curve25519Scalar` and `Curve25519Point` represent the pinned Midnight native types. The point type is the prime-order Edwards group and uses Ed25519 compressed point bytes.

```lean
import Noctium.Frontend
open scoped Noctium

noctium_circuit scaledEdwardsKey where
  private key : Curve25519Point
  private factor : Curve25519Scalar
  output keyBytes : Bytes 32 := disclose(foreignToBytes(curveMul(key, factor)))
end
```

The explicit source types preserve field role and family. Multiplication takes a point and its matching Scalar. A Base field is not a Scalar. Private values and derived results need `disclose` before a public return or ledger write.

## Encoding and identity

Base and Scalar use two native Field atoms. Point uses four: two encoded x limbs followed by two encoded y limbs. The [foreign field codec](../designs/foreign-types.md) still shifts field values by one before splitting them into limbs. Curve25519 Scalar carries 204 low bits in its first Field atom. Base and point coordinates carry 192 low bits. The native scalar configuration uses five 51-bit limbs, grouped four then one.

Point bytes occupy 32 bytes. Identity encodes as `01` followed by 31 zeros. Its coordinates are `(0,1)`, and both extraction and construction accept identity. Source values use one logical identity representation. Decoding and coordinate construction normalize those coordinates to `identity`; a raw duplicate affine identity is rejected.

Use `curve25519Point(x, y)` for literal prime-subgroup coordinates and `curve25519Identity()` for the identity. [Affine point literals](foreign-transport.md#affine-point-literals)

The base modulus is `2^255 - 19`. The scalar modulus is `2^252 + 27742317777372353535851937790883648493`. Field byte decoding reduces little-endian input modulo the selected field. Canonical SDK inputs instead reject modulo aliases. Point byte decoding requires exactly 32 canonical bytes and rejects points outside the prime-order subgroup.

## Validation boundary

Curve membership alone does not establish prime-subgroup membership. The Lean reference model checks canonical coordinates, the Edwards equation and multiplication by the subgroup order. It uses projective coordinates to avoid repeated inversions. The Rust runtime delegates subgroup and canonical codec checks to the pinned native implementation.

Zero inversion and invalid point construction or decoding reject when active. Inactive structured guards use valid substitutes, including the encoded identity for point decoding. Eager selection retains operand evaluation.

[Curve25519Encoding.lean](../../tests/Curve25519Encoding.lean) checks the reference model and emits seven field vectors plus identity and generator encodings. The [native codec case](../../runtime/tests/curve25519_codec.rs) compares those exact vectors and checks canonical and subgroup boundaries. [Curve25519.lean](../../tests/Curve25519.lean) and its [native checker case](../../runtime/tests/curve25519.rs) check three typed public inputs, 15 typed results, 73 private fields, arithmetic, coordinates, byte conversions, four-field point storage and inactive guarded defaults. Changed public transcript data, active invalid decoding and zero inversion reject. Both host execution and the raw native preimage reject the active failures.

## Typed witness callbacks

[Curve25519Witness.lean](../../tests/Curve25519Witness.lean) declares two
callbacks for a Scalar and a Point. The circuit adds one to the returned
scalar and doubles the returned point. Both results must match the public
expectations. The [Rust check](../../runtime/tests/curve25519_witness.rs) uses
fresh compiler sidecars for the typed session, then passes the completed
inputs to the native relation checker. Both callbacks return values that
differ from their arguments. The point callback rejects the codec test's
order-two point and accepts a valid retry.

```sh
scratch=$(mktemp -d)
trap 'rm -rf "$scratch"' EXIT
lake exe noctium compile tests/Curve25519Witness.lean \
  --target profiles/midnight-ledger-9-zkir-3.2.1-target.json \
  --emit ledger --emit witness --output "$scratch/compiled"
CARGO_TARGET_DIR="$scratch/rust" NOCTIUM_CURVE25519_WITNESS_ARTIFACTS="$scratch/compiled" \
  cargo test --manifest-path runtime/Cargo.toml --locked --no-default-features \
  --features zkir-321 --test curve25519_witness -- --ignored
```

The check covers source lowering, typed callbacks and native relation
checking on ZKIR 3.2.1. [Nested ledger trees](foreign-trees.md) also support
the three Curve25519 kinds. Formal preservation and broader storage and
deployment qualification remain under the [full native goal](../compatibility/GOAL.md).
